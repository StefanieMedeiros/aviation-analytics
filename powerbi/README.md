
# Power BI — Aviation Analytics

Esta pasta é destinada ao relatório desenvolvido
no Power BI Desktop.

O painel apresenta análises do transporte aéreo
brasileiro com dados da ANAC, incluindo:

- Indicadores estratégicos e operacionais
- Evolução temporal e comparações anuais
- Análise de companhias aéreas
- Análise de aeroportos e rotas
- Participação de mercado
- Segmentação de companhias aéreas

Arquivo principal: Aviation Analytics (.pbix)
